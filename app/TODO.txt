# Getting Started — Phase 1

Phase 1 goal: drop cert PDFs in `certs/`, run one script, get a clean CSV
in `output/` that you upload to Tableau by hand. Nothing personal touches git.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # then paste your Anthropic API key into .env
```

Get an API key at https://console.anthropic.com/settings/keys if you want
the AI categorization step (recommended, but optional — see below).

## Run it

1. Drop cert PDFs into `certs/` (already gitignored — safe).
2. Run:
   ```bash
   python parser/parser.py
   ```
3. Open `output/skills.csv` — also gitignored, safe.

Skip the AI step (faster, no API key/cost, leaves `category` blank for certs
without an explicit "Skills:" line) with:
```bash
python parser/parser.py --no-llm
```

## What you get in the CSV

| column | how it's filled |
|---|---|
| `cert_name` | best-guess from PDF text, filename fallback |
| `issuing_org` | matched against a known-provider list in `parser.py` |
| `date_completed` | regex-matched date in the PDF |
| `hours` | regex-matched "N hours" / CEU / PDU / CPE |
| `category` | one of the top-level buckets in `parser/categories.json` |
| `subcategories` | one or more from that category's list |
| `skills` | explicit "Skills:" line if present, else AI-inferred |
| `source_file` | which PDF this came from |
| `needs_review` | `yes` if no category could be assigned — check these by hand |

## Tuning it to your certs

- **`parser/categories.json`** is your taxonomy. Edit the categories/subcategories
  to match your actual field so the AI step (and your Tableau charts) stay
  consistent. I seeded it with IT-support/networking/education-tech buckets
  based on the job posting already in `jobs/DPUST.txt` — adjust freely.
- **`KNOWN_ORGS`** in `parser.py` — add any cert providers I didn't cover.
- If a lot of your certs *don't* have selectable text (scans/photos), that's
  a different extraction path (OCR) — let me know and we'll add it.
